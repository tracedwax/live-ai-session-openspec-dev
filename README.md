# OpenSpec for Devs: Spec to Design and Tasks

A hands-on developer session, about 75 minutes. It picks up where the product session left off: a spec comes to you, and you turn it into a design and a task list, one small full-stack increment at a time.

Today's flow is `/opsx:explore`, then `/opsx:new`, then `/opsx:continue` one artifact at a time (proposal, spec, design, tasks). Keep the proposal and spec identical to the Jira ticket; the design and tasks are your work. No code today. Going forward, the one-shot command is `/opsx:propose`.

Built in Claude Code and VS Code with the Jira MCP and OpenSpec, on the Opus model. This is a developer session; the two breakouts are developer rooms split for size.

The site is a Docsify site in docs/, served via GitHub Pages from /docs on main. Start at docs/README.md.
